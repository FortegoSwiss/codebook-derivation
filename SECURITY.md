# Security policy

Report suspected vulnerabilities privately through GitHub's
**Security → Advisories → Report a vulnerability** form:

[Report a vulnerability](https://github.com/FortegoSwiss/codebook-derivation/security/advisories/new)

A GitHub account is required. Do not report vulnerabilities in public issues.

Include the component version or commit, the impact and steps to reproduce
using synthetic inputs. Never include real wallet mnemonics, RootKeys, UserKeys,
Recovery Codes, transport keys or live backups.

See [README](README.md) for this component's security boundaries.
